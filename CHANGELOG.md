# Changelog

## 0.1.2 — Chapter mapping and header estimate

- Preserve chapter order when multiple TOC entries start on the same rendered page.
- Show the correct next chapter title and duration together.
- Add a compact chapter-time estimate to KOReader's top status line, with a settings toggle.
- Put **One More Chapter** first in the default reader **Tools** menu page.

## 0.1.1 — Reader Tools shortcut

- Move **One More Chapter** directly into the reader's **Tools** tab.
- Expand installation and Kindle testing instructions.

## 0.1.0 — EPUB time-budget MVP

- Add external KOReader plugin metadata and reader-menu entry for EPUBs.
- Estimate current and next chapter time from KOReader page pace, with explicit uncertainty ranges.
- Add 10, 15, 20, and 30 minute presets plus custom budgets and a configurable safety buffer.
- Recommend a chapter stopping point without changing reading position.
- Add manual seconds-per-page pace for missing or disabled statistics.
- Add namespaced settings and version-checked plugin ZIP packaging.
